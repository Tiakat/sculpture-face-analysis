2 · Object record (optional — leave unknown fields empty; the platform proposes culture / region / period / material from the reference corpus after analysis)

Metadata firewall: culture, region, period and material are stored with the object and used only after analysis for grouping and affinity. They cannot influence the expression or morphology computation.

Four separated layers

  1. Objective visual information — quality gate, 478 landmarks per face (multiple faces per image), pose, symmetry
  2. FACS-inspired action units — implied configuration for depicted faces; facial-action estimate for photographs of people
  3. Expression category — probabilities, confidence, explicit UNKNOWN, stability under lighting/perturbation
  4. Historical / cultural interpretation — reference retrieval and morphological affinity by culture, region, period or material, computed on the reference sample after the facial layers

Difficulty level 0–6 (clear frontal → abstract) is reported per face so performance can be stated per level rather than as one number.
